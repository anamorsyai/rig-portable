# Writeup Summarizer

## Key Extraction
- Vulnerability class (IDOR, SSRF, etc.)
- Target type (SaaS, API, web app)
- Discovery method (manual, automated, lucky)
- Exploitation technique (payload, bypass)
- Impact achieved (data, ATO, RCE)
- Bounty paid (if disclosed)

## Actionable Intel
- Reusable payloads from writeups
- Bypass techniques for common defenses
- Chaining patterns (low -> critical)
- Tools and configurations used

## Pattern Recognition
- Which vuln classes are trending
- Which tech stacks are most vulnerable
- Which bypass techniques work repeatedly
- Which impact demonstrations get paid

## Sources
- Medium security blogs
- Bug bounty writeup sites
- Personal blogs of top hunters
- Conference presentations
