# HackerOne Intelligence

## Report Mining
- Filter by program, severity, bounty amount
- Extract: vulnerability class, technique, payload, impact
- Track which vuln classes get paid most
- Learn from triage decisions (accepted vs informative)

## Pattern Extraction
- Common vuln classes per tech stack
- Effective bypass techniques
- Impact demonstration methods
- Report structure that gets accepted

## Technique Library
- Auth bypass patterns that got paid
- IDOR variations with high bounties
- SSRF chains that worked
- Race condition exploits with proof

- HackerOne Hacktivity (public disclosed reports)
- HackerOne blog posts
- Bug bounty writeups on Medium
- Security conference talks
- GitHub security advisories
