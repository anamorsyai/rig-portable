# JavaScript Deep Analysis

## Secret Extraction
- API keys and tokens
- Hardcoded credentials
- Internal API endpoints
- Backend URLs

## Endpoint Discovery
- All fetch/axios/XMLHttpRequest calls
- GraphQL queries and mutations
- REST API endpoints
- WebSocket connections

## Hidden Functionality
- Debug functions
- Admin-only features
- Beta/hidden features
- Feature flags

## Environment Variables
- Config objects
- Environment-specific URLs
- Feature toggles
- API version selectors

## Tools
- LinkFinder for endpoint extraction
- SecretFinder for secret detection
- JSLuice for comprehensive analysis
- Custom regex patterns
