# Email & User Enumeration

## Email Discovery
- Hunter.io API
- Email format: first.last@, flast@, firstl@
- LinkedIn profiles
- GitHub commit emails
- DNS MX records

## User Enumeration
- Registration form (email taken = user exists)
- Login form (different errors for valid/invalid)
- Password reset (email not found vs sent)
- API responses (user data leakage)

## Social Media
- LinkedIn company employees
- Twitter profiles
- GitHub contributors
- Conference speakers

## Breach Data
- Have I Been Pwned
- Breach databases (if accessible)
- Credential dumps

## Impact
- Targeted phishing
- Password spraying
- Social engineering
- Account enumeration
